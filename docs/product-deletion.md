# حذف المنتجات مع حفظ السجل المالي

الحذف يضع `Product.deletedAt` ويؤرشف المنتج ويعطّل خياراته داخل transaction واحدة. يتطلب صلاحية إدارة الكتالوج وكتابة «حذف» للتأكيد. يختفي من المتجر وقوائم المنتجات والمخزون واختيارات المجموعات، ولا يمكن لمحرر قديم إعادة نشره أو تعديل مخزونه.

تبقى الطلبات وبنودها وأسعارها ومجاميعها والفواتير وسجل المخزون والصور والخيارات وعضويات المجموعات محفوظة. تبقى المبيعات التاريخية ضمن إحصاءات الطلبات؛ عدد المنتجات الحالي يستبعد المحذوف. إلغاء طلب قديم يظل يعيد المخزون مرة واحدة، دون إعادة نشر المنتج. لا تُحذف ملفات Cloudinary ولا تُرسل إشعارات بسبب حذف المنتج.

الأرشفة مختلفة: يمكن إرجاع المؤرشف للبيع من الإدارة. المحذوف لا يظهر في قائمة المؤرشفات، ولا يوجد زر استعادة للمحذوف في هذا الإصدار. تبقى slug وSKU محجوزة لهويته القديمة؛ المنتج الجديد يحتاج قيماً مختلفة. المنتجات المحذوفة ليست بديلاً عن إدارة مرتجعات الطلبات أو تسوية المخزون.

## التفعيل

1. قبل نشر هذا الإصدار، شغّل [product-deletion.sql](../prisma/additive/product-deletion.sql) مرة واحدة على قاعدة البيئة المستهدفة. الملف إضافي وقابل للتكرار؛ لا يحذف أي بيانات.
2. تحقّق من وجود العمود:

```sql
SELECT column_name, data_type, is_nullable
FROM information_schema.columns
WHERE table_schema = 'public' AND table_name = 'Product' AND column_name = 'deletedAt';
```

3. بعدها اختبر المعاينة بحساب يملك صلاحية الكتالوج. جرّب حذف مسودة أُنشئت خصيصاً للاختبار، وألغِ التأكيد مرة قبل تنفيذ الحذف. لا تختبر بحذف منتج حقيقي.
4. تأكد من اختفاء المسودة من قائمة المنتجات والمخزون والمتجر. اختبارات السجل المالي الآلية تعمل على PostgreSQL معزول، ولا تحتاج طلباً حقيقياً أو رسالة Telegram.
5. ادمج بعد اكتمال التحقق. لا تشغّل seed أو reset أو db push لتفعيل الميزة.

تراجع الكود آمن مع بقاء العمود الإضافي، لكنه قد يعرض المحذوف ضمن المؤرشفات في الإصدار القديم؛ لا تعدّل تلك السجلات أثناء التراجع. لا تُسقط العمود ولا تمسح السجلات لاسترجاع الكود.

## التحقق الآلي

`npm run test:product-deletion` يفحص الصلاحية والتأكيد، حفظ الأرقام والبنود، اختفاء المنتج، منع إعادة التفعيل والتعديل من صفحات قديمة، تكرار الحذف، إلغاء الطلب القديم وإرجاع مخزونه مرة واحدة، وفشل/إلغاء/نجاح واجهة التأكيد.
