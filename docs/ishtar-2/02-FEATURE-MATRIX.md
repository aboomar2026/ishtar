## Shared acceptance contract

Each implemented row must include loading, empty, invalid/unavailable, success, denied/offline and retry states as applicable; Arabic RTL; keyboard and assistive labels; reduced motion for animation; mobile target review; server authorization and active-item validation. Exact fixtures and browser gates are in 06.

Proposed first-party event names: `search_submitted`, `search_suggestion_selected`, `product_quick_view_opened`, `wishlist_added/removed`, `recent_product_viewed` (local only), `curated_item_added`, `look_opened`, `product_shared`, `checkout_succeeded`, `admin_new_order_received`, `notification_read`, `push_subscription_enabled`. Define payloads with IDs only, no search/customer PII; events are a specification, not installed telemetry. Do not add third-party analytics or derive conversion rates without approved collection/consent and a real denominator.

Order correctness/auth/reliability gates precede feature expansion. F06/F07 require actual curations; F08/F15/F16/F31/F32 and outbound retention work should not delay a trustworthy core launch.
